# 사내 LLM 연결 (Gemma 등)

기획서 분석 · TC 작성 · TC 와 화면 연결 · AI 테스트를 **회사 안 서버의 모델**로 합니다.
기획서 · 화면 캡처 · TC 가 외부 AI(Gemini · Claude · ChatGPT)로 나가지 않습니다. 테스트 실행은 이전과 같이 Playwright 입니다.

## 1. 무엇이 어떻게 바뀌나

| 단계 | 외부 AI | 사내 LLM |
|---|---|---|
| 기획서 PDF 읽기 | PDF 파일 그대로 전송 | 앱이 **글자 + 페이지 그림(앞 12쪽)** 으로 바꿔 전송. 화면 시안 · 흐름도 · 표는 그림을 보고 판단 (그림을 읽는 모델일 때) · 글자가 없는 스캔 PDF 도 그림으로 전달 |
| 이미지 기획서 · AI 테스트 화면 캡처 | 이미지 전송 | 같음 (그림을 읽는 모델 필요) |
| 결과 형식(JSON) | 형식 보장 | 형식 강제 → 안 되면 JSON 모드 → 깨지면 한 번 다시 요청 |
| 기다리는 시간 | 수십 초 | 서버 성능에 따라 수 분 (최대 15분 기다림) |
| 로그인 화면 AI 전송 동의 | 처음 한 번 물음 | 묻지 않음 (외부로 나가지 않음) |

## 2. 추천 모델

| 모델 | 필요한 GPU 메모리(대략) | 비고 |
|---|---|---|
| **gemma3:27b** (기본값) | 약 17~24GB (4bit) | 그림 · 한국어 · JSON 모두 무난. 한 대로 모든 작업 |
| gemma3:12b | 약 8~12GB | 작은 GPU 용. 품질은 떨어짐 |
| gpt-oss:20b | 약 16GB | 글(TC 작성 · 연결)만. **그림을 읽지 못함** → 기획서 그림 · AI 테스트 불가 |

모델 · 라이선스는 무료이며 상업적 사용이 가능합니다 (각 라이선스 조건은 법무 확인 권장).

## 3. 서버 준비 (Ollama 예시)

1. 모델을 돌릴 PC · 서버(GPU 권장)에 Ollama 를 설치합니다: https://ollama.com/download
2. 모델 받기:
   ```
   ollama pull gemma3:27b
   ```
3. **입력 길이(context) 늘리기 — 꼭 필요합니다.** 기본값이 짧아 기획서 · TC 목록이 잘립니다 (잘리면 결과가 엉터리가 되거나 JSON 이 깨짐).
   Windows: 시스템 환경 변수에 `OLLAMA_CONTEXT_LENGTH` = `32768` 을 추가하고 Ollama 를 다시 시작.
   (메모리가 부족하면 16384. 기획서가 길면 더 크게)
4. 다른 PC 에서 이 서버를 쓰려면 (사내 공용 서버):
   - 환경 변수 `OLLAMA_HOST` = `0.0.0.0` 을 추가하고 Ollama 를 다시 시작
   - **방화벽에서 11434 포트를 사내 IP 대역에만 허용** (Ollama 는 기본적으로 인증이 없음 — 인터넷에 열지 말 것)
   - 서버 앞에 인증이 있는 프록시를 두면 앱의 API Key 칸에 그 키를 넣습니다
5. vLLM · LM Studio · llama.cpp 서버도 OpenAI 호환 주소(`…/v1`)가 있으면 똑같이 쓸 수 있습니다. vLLM 은 `--max-model-len` 으로 입력 길이를 정합니다.

## 4. 앱 설정

1. 상단 **AI 설정** → **사내 LLM (Gemma 등 · OpenAI 호환 서버)** 선택
2. **서버 주소**: 같은 PC 면 비워 두기(기본 `http://127.0.0.1:11434/v1`), 사내 서버면 `http://서버주소:11434/v1`
3. **모델**: 비워 두면 `gemma3:27b`. 다른 모델이면 서버에 받은 이름 그대로 (`ollama list` 로 확인)
4. **연결 확인** → "연결됨 · 모델 … 있음" 이 나오면 저장
5. API Key 는 서버가 요구할 때만 입력 (이 PC 의 `.env` 에만 저장)

## 5. 잘 안 될 때

| 증상 | 확인 |
|---|---|
| "사내 LLM 서버에 연결할 수 없습니다" | 서버가 켜져 있는지 · 주소(끝이 `/v1`) · 방화벽 |
| "모델 … 이(가) 서버에 없습니다" | 서버에서 `ollama pull <모델>` · 모델 이름 오타 |
| "응답을 JSON으로 해석하지 못했습니다" | 입력 길이(context) 늘리기 · 더 큰 모델 · 기획서를 나눠 첨부 |
| TC 가 엉뚱하거나 너무 적음 | 입력 길이가 잘렸을 가능성이 큼 → context 늘리기. 그래도 부족하면 더 큰 모델 |
| 화면 시안을 반영하지 않음 | 그림을 읽는 모델인지(gemma3 는 됨, gpt-oss 는 안 됨) |
| 매우 느림 | GPU 없이 CPU 로 돌고 있을 가능성. `ollama ps` 로 확인 |

## 6. 품질 확인 방법

같은 기획서 · 같은 TC 파일로 외부 AI 와 사내 LLM 결과를 비교하세요 (AI 설정에서 공급자만 바꿔 실행).
비교할 것: 만든 TC 수 · 고쳐야 할 TC 수 · 내 TC 대비 자동화 현황의 "자동 실행" 수 · AI 테스트의 실제 문제 / 오탐 수.
